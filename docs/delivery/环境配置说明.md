# 环境配置说明

> 全部配置经环境变量或 .env 注入（12-Factor）；模板见 deploy/.env.example。密钥不入库。

## 变量表

| 变量 | 默认 | 说明 |
|------|------|------|
| APP_ENV | dev | dev/test/prod；prod 时登录 Cookie 加 Secure |
| HOST / PORT | 127.0.0.1 / 8000 | 监听地址端口（生产置于 Nginx 后）|
| LOG_LEVEL | INFO | DEBUG/INFO/WARNING/ERROR |
| DATABASE_URL | sqlite:///./app.db | 可切 postgresql://（需另装驱动）|
| RETENTION_DAYS | 90 | 兼容字段（保留）；实际运行语义：每日 02:00 日清（见 CLEANUP_AT）|
| CLEANUP_AT | 02:00 | 每日 02:00 清空前日全部问诊数据（挂号日重置）；同数会使用寿命到期点 |
| AI_PROVIDER | mock | **mock=无Key全功能演示** / mimo=真实MiMo平台 |
| AI_BASE_URL | https://api.xiaomimimo.com/v1 | OpenAI 兼容网关地址 |
| AI_API_KEY | （空）| mimo 模式必填，控制台 sk-xxxxx |
| AI_CHAT_MODEL / AI_TTS_MODEL | mimo-v2.5 / mimo-v2.5-tts | 模型名可随平台更迭热切换 |
| AI_TTS_VOICE | 冰糖 | 内置音色：mimo_default/冰糖/茉莉/苏打/白桦…（中文女声，适老化）|
| AI_TIMEOUT_SECONDS | 25 | 上游超时（<30s 总预算）|
| AI_MAX_ROUNDS | 30 | 问诊轮次上限（PRD F3-R6，2026-08-24 由 10 调增至 30）|
| SECRET_KEY | （空）| 生产必改的随机串（≥32字符）|
| DOCTOR_USERNAME / DOCTOR_PASSWORD | admin / 空 | 仅首次建库时引导创建管理员 |
| SESSION_TTL_MINUTES | 30 | 医生会话30分钟无操作登出（PRD F6-R5）|
| LOGIN_MAX_FAILS / LOCKOUT_SECONDS | 5 / 600 | 登录锁定策略（PRD F6-R4）|
| PATIENT_RATE_LIMIT | 60/min | 患者端接口限流（每IP每分钟，医院共享出口20人同刷场景）|
| SESSION_MAX_PER_IP / SESSION_MAX_TOTAL | 30 / 500 | 活跃问诊会话上限（ADD-2 防膨胀；30=共享出口20人同刷场景值）|
| MAX_AUDIO_BYTES | 4000000 | 单轮音频解码后字节上限 |

## 三环境切换

- 开发：`cp deploy/.env.example server/.env` → 默认即 mock 全功能
- 测试：pytest 自带 tmp SQLite + mock，无需外部依赖
- 生产：deploy.sh 自动生成 .env 后**必须手改** SECRET_KEY/DOCTOR_PASSWORD/AI_PROVIDER/AI_API_KEY
